So geht's

Setze auf das Brett so viele Damen, wie es Zeilen hat:

  • genau eine Dame in jeder Zeile,
  • genau eine in jeder Spalte,
  • genau eine in jeder Farbregion,
  • und keine zwei Damen dürfen sich berühren – auch nicht schräg.

Tippe ein Feld einmal für ein ✕ (hier kann keine Dame stehen) und noch einmal für eine Dame. Mit gedrückter Maus oder dem Finger kannst du über mehrere Felder ziehen, um sie mit ✕ zu markieren. Konflikte werden rot schraffiert.

Jedes Rätsel hat genau eine Lösung – raten ist nie nötig. Jeden Tag gibt es ein neues, über ⇄ beliebig viele zum Üben.
